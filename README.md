# Yicheng (Eason) Fan — Personal Portfolio

A single-file static website built as a supplement to my Common App application.
No build step, no dependencies — just open `index.html` or host it anywhere.

## Deploy on GitHub Pages

1. Create a new GitHub repository and upload the contents of this folder (or just `index.html`).
2. In repo **Settings → Pages**, set **Source** to `Deploy from a branch`, branch `main`, folder `/ (root)`.
3. Save — your site goes live at `https://<username>.github.io/<repo-name>/`.

Everything (photos, videos, links) is served from CDN URLs already embedded in the file, so no extra assets are needed.
